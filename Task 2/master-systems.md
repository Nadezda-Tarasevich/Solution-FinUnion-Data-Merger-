### Матрица мастер-систем бизнес-сущностей компании FinUnion Group: промежуточное и целевое состояния

|сущность|источник AS-IS|мастер-система (3 месяца)|целевая мастер-система|связь с BIAN|обоснование|
|-|-|-|-|-|-|
|Клиент (Customer)<br />|FU CRM, RB CRM, FU Core, RB Core<br />|MDM (Customer Hub) — золотая запись клиента на основе FU CRM с дополнением из RB CRM|MDM (Customer Hub) — единый источник правды для всех систем|Party Reference Data Directory<br />|FU CRM — операционная система с наибольшим объёмом актуальных данных. MDM строится на её основе с матчингом записей из RB CRM. Целевое состояние — MDM как единственный источник для синхронизации во все системы (FU CRM, RB CRM, FU Core, RB Core)|
|Договор (Agreement)<br />|FU Core, RB Core, FU CRM, RB CRM<br />|FU Core (для новых договоров) + ESB (для синхронизации существующих из RB Core)|FU Core (единая автоматизированная банковская система (АБС))<br />|Product Access<br />|FU Core — более современная и гибкая АБС. Договоры RB Core мигрируются поэтапно через ESB. На 3 месяца — FU Core как мастер для новых договоров, RB Core — как источник для существующих (с синхронизацией). На 12 месяцев — все договоры в FU Core.|
|Счёт (Account)<br />|FU Core, RB Core<br />|FU Core (для новых счетов) + ESB (для синхронизации остатков из RB Core)|FU Core (единая АБС)<br />|Current Account / Savings Account / Loan Account<br />|Аналогично договорам. Счета физически находятся в двух АБС. На 3 месяца — FU Core мастер для новых, RB Core — источник для существующих с синхронизацией остатков. Цель — полная миграция в FU Core к 12 месяцам.|
|Карта (Card)<br />|FU Cards, RB Cards<br />|FU Cards (для новых карт) + синхронизация статусов из RB Cards|FU Cards (единый карточный процессинг)<br />|Card Management<br />|FU Cards — более современный процессинг. Карты RB Cards не мигрируются физически, а перевыпускаются в FU Cards по истечении срока. Статусы синхронизируются через ESB.|
|Транзакция (Transaction)<br />|FU Core, RB Core, FU Cards, RB Cards<br />|федеральная (Fed) DWH (единая витрина транзакций)<br />|Data Lakehouse + Fed DWH (витрины для отчётности)<br />|Transaction Authorization + Transaction Clearing + Transaction Settlement|Транзакции не имеют единой мастер-системы — они всегда рождаются в операционных системах (FU Core, RB Core, FU Cards, RB Cards). Мастером является слой аналитики (Fed DWH → Data Lakehouse), где данные очищаются, дедублицируются и становятся единым источником для отчётности.|
|Платёж (Payment)<br />|FU Core, RB Core (РКО), FU Cards<br />|FU Core (единый платёжный шлюз) + ESB (для синхронизации из RB Core)|FU Core (единый платёжный шлюз)|Payment Execution<br />|Платёжные инструкции должны обрабатываться через единый шлюз для контроля ликвидности и AML. RB Core подключается к шлюзу FU Core через ESB. Цель — полный перевод РКО на FU Core.|
|Продукт (Product)<br />|FU Core (справочник), RB Core (справочник)<br />|MDM (единый справочник продуктов на основе FU Core)<br />|MDM (единый справочник продуктов )<br />|Product Catalog + Product Design<br />|Справочники продуктов — классический случай для MDM. На 3 месяца — маппинг продуктов FU и RB, создание единого справочника. На 12 месяцев — MDM как единственный источник для всех систем (FU Core, RB Core, FU CRM).|
|Обращение (Interaction)<br />|FU CRM, RB CRM<br />|FU CRM (единая CRM) + ESB (для синхронизации исторических обращений из RB CRM)|FU CRM (единая CRM)<br />|Customer Relationship Management<br />|FU CRM выбрана как база для единой CRM. Обращения из RB CRM синхронизируются через ESB. Цель — полное отключение RB CRM к 12 месяцам.|
|Сегмент клиента (Segment)<br />|FU CRM, RB CRM, FU DWH<br />|MDM (единый справочник сегментов) + FU DWH (правила расчёта)|MDM (справочник) + Data Lakehouse (расчёт сегментов)<br />Segment Management|Segment Management<br />|Справочник сегментов — в MDM. Правила расчёта сегментов — в аналитическом слое (Data Lakehouse). На 3 месяца — базовый маппинг сегментов FU и RB.|
|Сотрудник (Employee)<br />|FU CRM (справочник), RB CRM, HR-система (AD)<br />|HR-система (Active Directory) — единый справочник сотрудников|HR-система (Active Directory) + IAM (управление доступом)<br />|Employee Management (расширение BIAN)<br />|Сотрудники — это корпоративные учётные записи. Мастер-система — HR-система (Active Directory). FU CRM и RB CRM получают данные сотрудни|
