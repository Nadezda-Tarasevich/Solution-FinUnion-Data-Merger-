### Data Mesh в целевой архитектуре FinUnion Group


**Принципы Data Mesh, применимые к кейсу**
Каждый бизнес-домен (Клиенты, Продукты, Счета) владеет своими данными и отвечает за их качество. Data Owner — руководитель домена.
Каждый домен публикует свои данные как Data Product с чёткими SLA, схемой и владельцем. Потребители получают данные через Data Catalog (DataHub).
Data Lakehouse + DWH + MDM предоставляют инфраструктуру для хранения, обработки и публикации Data Products. Airflow — оркестрация, DataHub — каталог.
DataHub обеспечивает единый каталог и lineage. Data Office устанавливает глобальные стандарты (форматы, качество, безопасность). Домены соблюдают стандарты.
